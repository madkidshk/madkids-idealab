這份招標文件（標書編號：`T/2026-009/F/S`）由環境及生態局（食物科）EEB(FB) 發出，旨在為降低食物中鹽和糖委員會（CRSS）採購電視及電台宣傳短片／聲帶（APIs）及相關影片製作服務 [1-3]。

以下為根據標書內容整理的詳細投標分析及項目規格：

---

① 背景同目的 (Background & Objectives)

* 背景：CRSS 自 2015 年成立以來，一直致力引遞及協調社區減鹽減糖宣傳工作 。局方在政府新聞處（ISD）協助下，推行首個以「少鹽少糖飲食習慣」為主題的電視及電台宣傳短片／聲帶（APIs）。

* 目的：

1. 提高公眾對 CRSS 及少鹽少糖宣傳活動（包括旗下各項重點計劃）的認識 。

2. 引發積極行為改變，並促進全港不同年齡層建立可持續的少鹽少糖健康飲食習慣，作為預防非傳染病及促進公眾健康的基石 。

* 出處：*Invitation Letter_API.pdf* [p.1]；*Quotation Document_API.pdf* Part III [p.85-86]。

---

② 目標受眾 (Target Audience)

* 標語（Slogan）及電視／電台 APIs：全港廣大公眾市民，涵蓋社區內所有年齡層及板塊 。

* 專題影片及改編短片：各項特定措施的標的受眾（例如餐廳、茶飲店、食品製造商等）。

* 出處：*Quotation Document_API.pdf* Part III [p.85]。

---

③ 傳意目標 / 核心訊息 (Communication Objectives & Key Messages)

1. 少鹽少糖依然美味：採納少鹽少糖（LSS）飲食是一項容易達成的健康習慣，而且絕不需要犧牲享用美味食物和飲料的樂趣 。

2. 隨時隨地皆可做到：無論係外出用餐（dining out）、叫外賣（ordering delivery food）或喺屋企煮食（cooking at home），每個人都可以做到少鹽少糖飲食 。

3. 吉祥物登場：必須於 APIs 中展現重塑／煥然一新的少鹽少糖吉祥物（「鹽少」及「糖小姐」），以最大化宣傳效果（吉祥物資料由政府提供）。

4. 展現核心計劃：API 須簡短展示 CRSS 旗下核心計劃（例如透過 QR code 或其他適當展示方式），包括 [7-9]：

* 少鹽少糖食肆計劃 (Less-Salt-and-Sugar Restaurants Scheme)

* 無糖星期五 (Less Sugar Friday campaign)

* 預包裝食品「鹽／糖」標籤計劃 ("Salt / Sugar" Label Scheme for Prepackaged Food Products)

5. 長期標語：建議一個適合 CRSS 及 LSS 運動長期使用的雙語響亮標語（impactful slogan, bilingual）。

* 出處：*Quotation Document_API.pdf* Part III [p.85-87]。

④ 影片及製作規格 (Production Specifications)

* 集數與長度：

* TV API：1 條，長度 30 秒 。

* Radio API：1 條，長度 30 秒 。

* 專題影片 (Two-minute video)：1 條，長度 2 分鐘（介紹 CRSS 各項重點措施）。

* 精華短片 (Short videos)：3 條，每條長約 10–15 秒（改編自 2 分鐘影片，重點展示個別措施）。

* 語言、字幕與配音：

* TV API：粵語（配繁體中文書面語字幕）及英文（配英文字幕）；須提供廣東話及英文旁白配音員 。

* Radio API：粵語、英文（獨白形式 monologue-type）及普通話 ；普通話配音員建議達到國家語言文字工作委員會普通話水平測試「一級乙等」或以上資歷 。

* 2分鐘影片及3條精華短片：粵語（配繁體中文書面語字幕）及英文（配英文字幕）。

* 拍攝與輸出技術規格：

* TV API 拍攝格式：首選 HDCAM, RED ONE 或同等格式；視乎創意概念亦可考慮 HDV 或單眼相機拍攝 。

* TV API 輸出格式：16:9 (HD) XDCAM HD422 at 50Mbps in MXF 及 HDCAM 。

* Radio API 音訊格式：商業電台／新城電台為 MP3，香港電台為 WAV (48kHz/16bit) [22-24]。

* 網絡無障礙版本：TV API 須額外提供符合 W3C Web Content Accessibility Guidelines (WCAG) 2.2 Level AA 標準的網絡版本 。

* 出處：*Quotation Document_API.pdf* Part III & Annex 4, 5, 6 [p.85, 87-89, 123, 127, 130]。

* 核心風格：訊息傳達須非常清晰、準確、簡明（clear, accurate, concise），同時具備高度吸引力、衝擊力、記憶點與說服力（impact, recall, resonance）[40-43]。

* 常見 approach： 以家庭／上班族／長者作主角，展示「揀有營菜式」情境；用醫生／營養師出鏡講解影響。

* Tone： 認真、少量幽默，偏「政策＋健康教育」。

* 「健康生活」、「防控糖尿病／心血管疾病」等 API / 宣傳

* 內容： 強調少鹽少糖作為其中一個健康生活元素，配合運動、不吸煙等。

* 視覺： 醫院場景、家庭吃飯場景、跑步等「標準健康影像」。

5.2 國際競品 / 同類創意做法

* 英國 / 歐洲 (Dept of Health / NHS / Public Health England)

* 針對議題： 減鹽減糖、肥胖、糖稅。

* 常見 approach： 用「視覺化糖量」（如一杯汽水倒出多粒方糖）；用「未來健康後果」（孩子現時飲食 vs 長大後健康問題）。

* Tone： 部分曾使用 shock tactic（黑暗背景＋器官損壞圖像）；近年轉趨生活化，強調「easy swaps」(換飲品、換零食)。

* 新加坡 / 亞太 (新加坡健康促進局)

* 針對議題： 少糖飲品、飲品分級、餐飲健康選擇。

* 常見做法： 強調「飲品 label 顏色」讓你簡單選擇；用 office workers / young adults 作主角。

* Tone： 機智幽默＋強烈 call to action，推「選健康不難」。

* WHO 及國際 NGO 線上 Campaign

* 內容： 教市民計算每日鹽／糖攝取；提醒預防高血壓、糖尿病。

* 視覺： 極簡插畫、資訊圖表、動畫 short clips。

* 調性： 非常「數據＋事實」導向，情緒較少。

6. 香港角色

* 政府部門協調： 環境及生態局（食物科）透過降低食物中鹽和糖委員會（CRSS）協調各部門推動減鹽減糖宣傳。

* 跨平台推廣： 利用傳統媒體、社交平台、KOL及餐飲平台合作，推動減鹽減糖訊息。

* 政策與實踐結合： 將減鹽減糖從政策宣示落實到餐廳、預先包裝食品及全民生活層面。
