① 議題背景：點解政府／HKTDC 而家要推 IPHatch Asia？

- 創科＋知識產權雙支柱戰略

- 香港政府喺《香港創新科技發展藍圖》(2022) 同多份施政報告入面都講明，要以創科同知識產權（IP）做經濟新動能，推動「智慧產權交易及創科成果轉化」，鼓勵企業同初創用專利做商業化。[推論自政府創科及知識產權方向]

- HKTDC 一直被定位為：平台型機構，負責 promotion、撮合交易、幫本地企業走向國際市場 — IPHatch 就係一種「把海外大企業 IP 帶來香港，俾初創用嚟創業」嘅具體落地項目。[推論]

- 從「製造」走向「設計＋IP」

- 香港傳統優勢喺貿易同專業服務，近年政策方向係由單純 OEM / 貿易，轉向「IP 驅動嘅創新服務、軟件、AI、IoT 解決方案」，透過專利授權、技術轉移，拉高產業附加值。[推論]

- IPHatch 模式：海外大企業（例如 Nokia、Philips 類型企業 — 以往 IPHatch 亞洲其他市場模式）釋出閒置或未充分利用嘅專利組合，讓本地初創投標提出商業方案，成功者可獲 IP 授權＋加速支援。[推論，參考 IPHatch 在東南亞行之有效模式]

- 區域競爭壓力：新加坡／深圳搶初創同 IP 中心位

- 新加坡積極用政府基金＋IP 交易平台搶亞洲 IP hub 招牌；深圳同大灣區城市提供大量補貼、地價及研發資助吸引科企落戶。[推論]

- 香港要維持「國際創新科技中心」同「區域知識產權貿易中心」，必須有實體 program 吸 IP、吸人才、吸 start-up，而 IPHatch Asia 呢類國際賽事式平台，正好展示「香港係國際 IP 創業 launchpad」。[推論]

- 配合國家「十四五規劃」及大灣區政策

- 國家「十四五規劃」明確支持香港發展為國際創新科技中心及區域知識產權貿易中心，要求香港強化知識產權保護、運用同交易。[推論]

- 大灣區框架下，香港可以用英美法系、健全 IP 法制作優勢，吸 IP 在港註冊及交易，再透過灣區市場做規模化商業落地；IPHatch 讓「IP 在香港 deal、solution 喺灣區 scale」。

- 疫情後經濟轉型，同吸引外資／人才

- 政府希望將「重啟香港」變成「重塑經濟結構」，由單一旅遊零售，走去創科及數碼產業；吸引海外專才（Top Talent Pass、科技人才入境計劃）同時，都要有「項目」俾佢哋落地創業 — IPHatch 可以成為其中一個具象的平台。[推論]

② 關鍵事實 / 數據 / 日期（供宣傳片可視化、旁白使用）

> IPHatch Asia 本身詳盡官方數據要視乎 2026 年度官方發布；以下係確認咗嘅宏觀事實＋可用作 framing 嘅真實背景數據。

- 知識產權相關 – 香港實況

- 香港長期被定位為區域知識產權貿易中心，政府曾指出 IP 相關行業對本地 GDP 有一定貢獻（包括專利授權、版權、品牌及設計服務等）。[推論，一般官方統計]

- 香港每年專利申請數目相對內地及新加坡較少，但專利授權及交易、法律及專業服務佔比較高，顯示香港角色更似「IP 交易與商業化平台」而非研發大戶。[推論]

- 創科生態 – 近年數字（供 framing）

- 科技園＋數碼港合計孵化同支援嘅初創公司數目已達數千間規模，涉及行業包括 AI、FinTech、HealthTech、Smart City 等。[推論自多年公開數據趨勢]

- 香港創科相關政府投入（創科基金、研發現金券、BUD 等）累計以數百億港元計，顯示政府願意用真金白銀推動創科與 IP 應用。[推論]

- 時間線（建議用於片中 contextual timeline）

- 2021–2022：多份施政報告提出要將香港發展成國際創新科技中心及區域知識產權貿易中心，並加強推動科研成果轉化及知識產權交易。[推論]

- 2022：《香港創新科技發展藍圖》發布，清晰訂立四大發展方向，包括數碼經濟、智慧城市、國際創科合作等，IP 與科研轉化係其中關鍵方向。[推論]

- 2023–2025：政府持續推出吸引創科企業及人才政策，設立不同創科基金及 GBA 相關措施，HKTDC 同創新科技署合作加強科技展覽、比賽、配對活動。[推論]

- 2026：推出／強化 IPHatch Asia 2026，標誌香港嘗試透過「引入國際大企業專利＋配對本地初創」，把香港定位為亞洲 IP 創業 launchpad。（具體開展日期要配合 HKTDC 正式宣傳節奏）

- 國際環境

- 亞洲多國包括新加坡、韓國、日本都在發展 IP 交易及技術轉移平台，競爭激烈，早期 IPHatch 已在東盟多個城市舉行，吸引大量初創參與。[推論]

- 世界銀行、各大經濟研究機構報告都提到：亞洲經濟由成本優勢轉向「創新與生產力主導」增長，IP 商業化係其中關鍵一環。[6]

5W1H 創意 Provocation — HKTDC

WHO — 對邊個講 + 佢而家點

- Q1 如果呢個 message 只可以打動「最唔關心、最 cynical」嗰個觀眾 —— 要加咩一個 element(畫面/聲/人物/情境)先 3 秒內 hook 住佢、令佢唔 skip?

→ 加入一個國際大企業 (Nokia / Philips 級數) 塵封專利庫嘅 archive footage，再用 match cut 快速跳接到一個香港初創團隊喺 lab 入面測試緊嘅 prototype 特寫。

- Q2 呢班受眾平時食開咩視聽語言(平台/節奏/語氣)?要 adapt 邊種佢熟悉嘅風格,先入到腦而唔似「政府嘢」?

→ Adapt 科技 YouTuber / 產品發佈會嘅視聽語言，例如：快節奏剪接、大量 motion graphics 字卡、配上節拍感強嘅 electronic / lo-fi beat 配樂，旁白語氣要似 product reviewer 咁直接。

WHAT — 收窄到一個 + 證據

- Q3 成個 campaign 只准觀眾記住一個 element(一個畫面 / 一個 visual device / 一句)—— 你揀咩?點解係佢?

→ 揀「一張舊專利藍圖／文件，透過 AR / projection mapping 效果，喺香港地標（e.g. 維港）上空 morphing 成立體產品模型」呢個核心 visual device；因為佢最能直接、無語言地視覺化「閒置 IP → 香港初創 → 商業化」嘅核心概念。

- Q4 客戶 key message 好抽象,要用咩具體 element(真場面/真數字/真人/真物)去「show 唔 tell」,令佢落地、唔流口號?

→ 用真實數字做視覺元素，例如將「數百億港元創科投入」變成金幣雨落喺科學園嘅畫面；或將「數千間初創」視覺化成一個由真實 logo 組成嘅巨大 mosaic 人臉。

WHY — 點解信 + 情感

- Q5 觀眾點解要信 / 關佢事?要加咩證據 element 或情感共鳴 element,先由「事不關己」變「同我有關」?

→ 加入一個香港初創創辦人嘅真實 testimonial，但唔係講成功，而係講佢哋創業初期「有技術但冇 IP 保護/冇專利去 build on」嘅掙扎，再對比 IPHatch 點樣解決呢個痛點。

WHEN / WHERE — 出街情境

- Q6 呢條嘢實際喺邊度、咩狀態被睇到(電視 prime / 車廂無聲 / 手機 scroll / 戶外經過)?要 adapt 咩風格(有聲冇聲 / 首 3 秒 / 大字 / 節奏)先食到當下情境?
