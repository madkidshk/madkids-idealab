由圖開始

🏠
先 rough 3D，再 Blender refine。呢頁係 mk lab 內部固定入口，唔使每次重新解釋流程。

輸入

  • 一張圖可以做 rough 3D，但四肢比例只係初稿。
  • 最好有正面 + 側面 + 背面，會準好多。
  • 如果目標係 3D printer，最後一定要做封閉 mesh 檢查。
Reference image Rough 3D Printable

輸出

rough model: GLB / OBJ / STL refined model: STL / 3MF / OBJ print check: non-manifold / watertight / scale
開 3D 模型流程 開 Blender refine script

1 先出 rough 3D

先用 image-to-3D 工具起草，重點係捉姿勢、輪廓、主體比例。呢一步唔追求 print-ready。

2 再入 Blender

將 rough mesh import 入 Blender，修四肢圓潤度、厚度、連接位同底部穩定性。

3 最後出檔

輸出 STL 或 3MF，然後重 import 檢查 mesh。未過檢查就唔當真係完成。
