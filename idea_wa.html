💬 Idea → WhatsApp

寫定 idea，夠鐘自動 send 去你 WhatsApp · HKT

🔑 一次性設定

呢個頁要用你自己一個 GitHub fine-grained token（只存喺你部機 browser，唔會入 repo）去寫入私人 queue。

  1. 開 GitHub → Fine-grained token
  2. Repository access → 揀 mk-idea-lab
  3. Permissions → Contents: Read and write
  4. Generate，copy 個 token 貼落嚟

📝 寫個 message

⏳ 排緊隊（0）

📨 已 send 紀錄
夠鐘由 GitHub Actions（每 5 分鐘）經 CallMeBot send。
🔒 訊息存喺私人 repo mk-idea-lab；apikey 只喺 GitHub Secrets，唔落 browser。

❓ 點用

  1. 寫個 message，揀個時間（即刻 / 預設 / 自訂）。
  2. 撳「排程」→ 入咗私人 queue。
  3. GitHub Actions cron 每 5 分鐘掃一次，夠鐘就經 CallMeBot send 去你 WhatsApp。
  4. 「即刻」會排去當下時間，下一個 cron tick（≤5 分鐘）到。要秒到就本機行 ./idealab now。
  5. send 咗會由「排緊隊」移去「已 send 紀錄」。

⚠️ cron 高峰期可能拖多幾分鐘，做提醒 OK，唔好當鬧鐘秒準。
