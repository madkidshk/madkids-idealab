1 · 寫 + 排程

寫個 message，揀個時間（即刻 / 預設 / 自訂），撳「排程」→ 入咗私人 queue。

2 · 夠鐘自動 send

GitHub Actions cron 每 5 分鐘掃一次，夠鐘就經 CallMeBot send 去你 WhatsApp。send 咗會由「排緊隊」移去「已 send 紀錄」。

3 · 「即刻」要幾快？

「即刻」會排去當下時間，下一個 cron tick（≤5 分鐘）到。要秒到就本機行 ./idealab now "…"。

⚠️ 注意

cron 高峰期可能拖多幾分鐘，做提醒 OK，唔好當鬧鐘秒準。Token 只存你 browser，唔入 repo。
