1. Background（背景）

為配合 2025 年《施政報告》公佈的措施，由食物環境衞生署（FEHD）與屋宇署（BD）成立的聯合辦事處（聯辦處/JO）將推出處理私人樓宇滲水的新調查及測試程序 [1]。政府希望透過新一輯電視及電台政府宣傳短片（API），向公眾宣傳這些旨在更有效解決滲水問題的加強措施 [1]。

2. Objective（目標）

提升公眾對聯辦處即將推出的新滲水調查程序及加強措施的認知；強調業主妥善保養物業及防止滲水的責任 [2]。具體需向受眾解釋精簡後的調查程序（包括使用紅外線熱成像分析及同步進行第二和第三階段調查），並促使收到「通知信」的業主主動及時進行檢驗和維修 [2]。

3. Key Message（核心訊息）

妥善保養物業、防止滲水，永遠是業主的責任 [3]。聯辦處在第一階段已引入紅外線探測以加快尋找滲水源頭；若發出「通知信」後業主仍未能在限期內完成維修，聯辦處將同步展開第二及第三階段調查，並會向不合作的業主追討相關測試費用 [3, 4]。

4. Deliverables（交付物）

  • TV API： 一條 30 秒電視宣傳短片，包含粵語（配繁體中文書面語字幕及手語）及英語（配英文字幕及手語）兩個版本 [5, 6]。需以 HDCam、RED ONE 或同等格式拍攝，輸出 16:9 (HD) XDCAM HD422 MXF 檔案 [5, 6]。手語視窗需佔畫面六分之一，位於右下角 [7, 8]。
  • Radio API： 一條 30 秒電台宣傳聲帶，包含粵語、英語（獨白形式）及普通話（要求一級乙等水平）版本 [9-11]。
  • 其他： 中英文口號（Slogan）、腳本、分鏡圖（Storyboard）、配音、原創或已獲版權許可的背景音樂 [10, 12-15]。

創意跳板 (Creative Springboard)

策略張力 (Strategic Tension) 樓上業主想玩「拖字訣」僥倖過關（以為查唔到源頭就唔使修） VS 聯辦處新程序「快、準、狠」打破拖延（紅外線秒搵源頭 + 同步調查 + 追討費用），「拖延的代價」隨時大過「主動維修的成本」。

創意機會 (Creative Opportunity) 將「查滲水」由大眾認知中的「冗長官僚程序」重塑為 「高科技執法行動」；將「業主防漏責任」由空泛的「道德呼籲」轉化為業主自身的 「精明避險/理財選擇」。

受眾觸發點 (Audience Trigger)

  • 情緒： 收到「通知信」時的慌亂與僥倖；怕被追討測試費用的「肉痛」感；怕麻煩但更怕惹官非的權衡。
  • 場景： 紅外線熱成像儀如「照妖鏡」般讓牆內暗漏無所遁形的視覺震撼；收到信件後「拆彈」般的倒數緊迫感。

品牌角色 (Brand Role) 聯合辦事處 (JO) —— 配備高科技、雷厲風行、賞罰分明的 「規則維護者」。唔再係慢吞吞或和稀泥的調解員，而係「講得出做得到」的執法部門。

推薦切入角度 (Recommended Angles)

  1. 科技照妖鏡 (視覺衝擊)： 以紅外線熱成像儀的「透視第一視角」貫穿全片，讓隱藏的滲水源頭無所遁形。帶出「搵源頭快過你諗」，打破業主「查唔到就唔使修」的僥倖心理。
  2. 精明算盤 (利益驅動)： 用誇張/幽默的「算帳」方式，對比「主動維修的成本」與「被追討測試費用 + 強制維修的代價」。帶出「自己搞掂最著數，拖延只會大出血」。
  3. 信件倒數 (緊迫行動)： 以收到聯辦處「通知信」為起點，營造倒數緊迫感。展示新程序「同步展開第二及第三階段」的雷厲風行，促使業主收到信後立刻行動，唔好等。
  4. 責任歸位 (當家作主)： 從「物業擁有者」的自豪感切入，反轉「漏水好煩」的負面情緒。強調妥善保養是業主的底線責任，保護物業價值由防漏開始。

要避開的伏 (Watchouts & DQ Risks)

  • 官方正名： 必須準確使用「聯合辦事處（聯辦處/JO）」，並清晰交代由「食物環境衞生署（食環署）」與「屋宇署」成立。切勿只講「政府」或混淆部門。
  • 程序準確性： 嚴禁誇大執法權力（如「直接罰款」或「強行入屋」）。必須準確表達：第一階段用紅外線；發通知信後不修，會「同步展開第二及第三階段」，並「追討相關測試費用」。
  • 語氣避忌： 切勿抹黑政府過往程序（不要說「以前好慢/好廢」），要聚焦「而家升級/更快更高效」。避免挑起階級或鄰里對立，保持政府專業中立。
  • 製作規格 DQ 位：
  • TV API 必須包含粵/英版本，手語視窗嚴格佔畫面 1/6 並置於右下角。
  • 輸出格式必須為 16:9 (HD) XDCAM HD422 MXF。
  • Radio API 普通話版本必須達「一級乙等」水平，切勿隨便找配音員敷衍。
